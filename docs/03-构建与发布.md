# 构建与发布

## 环境

| 项 | 版本 |
|---|---|
| JDK | 17 |
| Android SDK | compileSdk 37（minorApiLevel 2），minSdk 31，targetSdk 37 |
| Gradle | 9.7.1（wrapper） |
| AGP | 9.4.0（自带 Kotlin 支持，不要再应用 `org.jetbrains.kotlin.android`） |
| Compose 编译器插件 | 2.4.10 |

`local.properties` 只写本机 SDK 路径，已在 `.gitignore` 中。

## 命令

```bash
./gradlew assembleDebug      # 调试包，可用 run-as 检查应用私有目录
./gradlew assembleRelease    # 发布包
```

产物：

```
app/build/outputs/apk/debug/app-debug.apk
app/build/outputs/apk/release/app-release.apk
```

## 签名

发布包使用仓库外的 keystore，通过仓库根目录的 `keystore.properties`（不进版本库）或环境变量读取：

```properties
storeFile=S:/local/keys/go2servicemode/release.jks
storePassword=<口令>
keyAlias=go2servicemode
keyPassword=<口令>
```

等价的 CI 变量：`GO2SM_KEYSTORE`、`GO2SM_STORE_PASSWORD`、`GO2SM_KEY_ALIAS`、`GO2SM_KEY_PASSWORD`。

没有签名材料时 `assembleRelease` 仍可构建，但会回退 debug 签名并打印警告——**这种包不能发布**。

### 发布证书

| 项 | 值 |
|---|---|
| 别名 | `go2servicemode` |
| 主体 | `CN=lots0, O=lots0` |
| 算法 | 4096 位 RSA / SHA384withRSA |
| 有效期 | 2026-10-25 → 2054-03-12 |
| 证书 SHA-256 | `176f2588f9b5b009f5dff42b7cd497f9d8462e74a68deb7a73a9b5ed51cbc9bd` |

签名方案为 v2。

**这把密钥是永久的。** 换密钥等于换应用，已安装的用户无法升级。keystore 与两个口令务必离线备份。

## 版本规则

- `versionName`：`0.0.1`、`0.0.2`…，展示为 `V0.0.1`
- `versionCode`：每次发版必须递增（当前为 `1`）
- 界面上的版本由三部分组成：`VERSION_NAME`、构建日期、以及**运行中 APK 自身的 SHA-256**（运行时读 `applicationInfo.sourceDir` 计算，不是写死的）

## 发布流程

```bash
# 1. 改版本号
#    app/build.gradle.kts: versionCode / versionName
# 2. 构建
./gradlew assembleRelease
# 3. 校验签名
apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
# 4. 记录校验和
sha256sum app/build/outputs/apk/release/app-release.apk
# 5. 打标签并发布
git tag -a v0.0.x -m "go2servicemode v0.0.x"
git push origin v0.0.x
gh release create v0.0.x app/build/outputs/apk/release/app-release.apk \
  --title "go2servicemode v0.0.x" --notes-file RELEASE.md
```

升级安装要求 `versionCode` 更大，且签名证书一致。

## 依赖

```kotlin
implementation("androidx.activity:activity-compose:1.13.0")
implementation("androidx.compose.foundation:foundation:1.12.0")
implementation("androidx.compose.ui:ui:1.12.0")

```

原生库需要从 APK 解压到磁盘后再加载，因此：

```kotlin
packaging { jniLibs { useLegacyPackaging = true } }
```

## 常见问题

| 现象 | 原因 |
|---|---|
| `Unresolved reference 'java'`（kts 内用 `java.text.*`） | Kotlin DSL 中 `java` 被 Gradle 扩展遮蔽，改为文件头 `import` |
| 启动崩溃、`IpSecService` 权限异常 | 清单缺少 `android.permission.INTERNET` |
| 安装被拒绝（-3001） | 设备侧构建类型校验，与本工程无关 |
| 发布包签名显示 debug | 缺少 `keystore.properties` 或环境变量 |
